## 一、一句话与情绪基调

**手绘任意图形,用一串旋转的圆把它重新画出来。**(21 字)

**情绪基调:沉静、精密、克制。**

不是"炫酷"。这是一个数学教具,画面应该像一页会动的讲义,用户是读者和调节者。所有兴奋感应该来自"看懂了"那一刻,而不是来自界面在喊叫。

强化这个基调的两个具体手段:

1. **只有一处是亮的**。整个画面里,墨黑的重建轨迹是唯一的高对比元素,辅助圆全部压到近乎不可见。
2. **全产品只有一处非功能性高光动效**(收笔落印);圆链、轨迹和正弦动点都直接解释数学关系。

## 二、视觉方向:墨迹(Ink on paper)

### 2.1 为什么是这个方向

候选过三个方向:星历(深蓝夜空 + 黄铜)、蓝晒(普鲁士蓝 + 象牙白)、墨迹(纸本白 + 墨黑朱红)。选定墨迹,理由:

- **差异化**。同场作品九成会是深色炫光。纸本白 + 墨黑在评审现场是唯一的,记忆点最强。
- **与旗匹配**。「教育文化」这面旗,一页会动的数学讲义比一场光效秀更贴题。
- **公式有地方放**。纸本天然容纳公式和批注,衬线体公式印在纸上不违和;暗色玻璃界面上放公式则会显得生硬。
- **性能余量大**。无辉光、无模糊图层,Canvas 每帧只画线。Playgrounds 的 Debug 模式下 60fps 压力显著小于暗色辉光方案。

### 2.2 我砍掉了什么

按设计准则要求,明确记录减法:

| 砍掉的 | 原因 |
|---|---|
| 辉光 / 霓虹拖尾 | 纸本方案的隐喻是"运笔",不是"发光"。墨不会发光 |
| 彩虹渐变轨迹 | 削弱形状可读性,且是 AI 默认审美的典型痕迹 |
| 粒子特效、动态背景网格 | 与数学结构抢注意力 |
| 纸张纹理 / 噪点贴图 | 纯装饰,不承载信息 |
| 明暗双主题 | 只做纸本一套。双主题是浪费一天工期 |
| 欢迎页 / 教程页 / 开始按钮 | 三分钟体验的第一杀手 |
| 音频合成(听见你的画) | 概念好,但一天工期内性价比最低 |

### 2.3 反 AI 默认审美的自查

设计准则 §13 列出的配色陷阱,逐条核对:

- 「近黑底 + 单一荧光色点缀」——**已避开**。这是第一轮方案(近黑 + 青色辉光)踩中的坑,已废弃。
- 「米白底 + 高对比衬线标题 + 陶土橙点缀」——**部分接近,已处理**。纸底选 `#F1F0EC`(偏冷)而非 `#F4F1EA`(偏暖);强调色选朱砂 `#B2352A` 而非陶土橙 `#D97757`,且朱砂只用于 3–4 像素大的点和线,绝不做色块铺陈;衬线体只用于公式,不用于标题。
- 「所有卡片同一圆角 + 同一软灰阴影」——**已避开**。全应用只有一个浮层面板,零阴影。
- 「全大写小标签 / 中间点串联元信息 / 数据标签用等宽字体」——**已避开**。

## 三、Design Tokens

### 3.1 颜色(6 个语义槽位)

```swift
enum Ink {
    static let paper      = Color(red: 0.945, green: 0.941, blue: 0.925)  // #F1F0EC 纸底
    static let panel      = Color.white.opacity(0.78)                      // 浮层面板
    static let ink        = Color(red: 0.102, green: 0.102, blue: 0.094)  // #1A1A18 主墨色
    static let graphite   = Color(red: 0.490, green: 0.478, blue: 0.451)  // #7D7A73 辅助线
    static let vermilion  = Color(red: 0.698, green: 0.208, blue: 0.165)  // #B2352A 朱砂
    static let muted      = Color(red: 0.102, green: 0.102, blue: 0.094).opacity(0.55)
}
```

**对比度核算**(纸底 `#F1F0EC` 为背景):

| 组合 | 对比度 | 用途 | 判定 |
|---|---|---|---|
| ink / paper | 约 15.4:1 | 重建轨迹、正文 | 远超 4.5:1 |
| muted(55% ink)/ paper | 约 5.6:1 | 次要文字、提示 | 达标 |
| vermilion / paper | 约 5.5:1 | 强调数值、选中项 | 达标 |
| graphite / paper | 约 3.9:1 | 辅助圆(非文字图形元素,要求 3:1) | 达标 |

辅助圆实际以 `graphite` 叠加透明度绘制,低于 3:1。这是**有意的取舍**:辅助圆是背景性的构造线,不承载必须辨认的信息,压暗它们是为了让主轨迹成为唯一焦点。此项记录在案。

**朱砂的语义是唯一的:当前正被用户操作或选中的量。** 不用于任何装饰。这条规则是整个配色系统的支点,不允许破例。

### 3.2 字体

| 角色 | 字体 | 理由 |
|---|---|---|
| 数学内容(公式、系数数值) | New York(`.serif` 设计变体) | 衬线体建立"讲义"气质;系统字体,零打包成本 |
| 界面(标签、按钮、提示) | SF Pro(系统默认) | 平台惯例 |

```swift
.font(.system(size: 17, design: .serif))   // 公式主体
.font(.system(size: 13))                    // 界面标签
```

两个字族区分度足够大(衬线 / 无衬线),符合"若用两个必须明显区分"的要求。

字号阶梯(6 级):`11 / 13 / 15 / 17 / 22 / 28`
行高:正文 1.5,公式 1.3

### 3.3 间距、圆角、动效

```
间距(4pt 基准):4 8 12 16 20 24 32 40
圆角阶梯:6(小控件) / 14(按钮) / 18(浮层面板)
页面边距:16
最小点击热区:44×44
```

| 动效类型 | 时长 | 缓动 |
|---|---|---|
| 按钮按下、选中态切换 | 120ms | easeOut |
| 单项公式展开 / 收起 | 260ms | spring(response: 0.35, damping: 0.8) |
| 收笔落印(唯一高光动效) | 800ms | 见 §4 |

必须响应 `accessibilityReduceMotion`:开启时,§4 的五阶段循环降级为"直接显示完成态 + 静态圆链 + 静态投影示意",不做绽放、移动点或淡出。

## 四、动效编排:一轮循环的五个阶段

暗色方案里动画的美感来自"发光",纸本方案里来自"运笔"。隐喻从能量换成书写,整套时序需要重排。

| 阶段 | 时长 | 画面 |
|---|---|---|
| **落笔** | 用户绘制期间 | 手指划过处实时留下石墨灰笔迹(`graphite`,线宽 3.0),略粗、有起收笔 |
| **起稿** | 0.9s | 手绘笔迹在 0.4s 内淡到 12% 透明度,成为「原稿幽灵」并常驻;辅助圆按 `0,+1,-1,+2,-2,…` 的固定频率顺序从链首到链尾出现,半径从 0 弹到真值(easeOut) |
| **运笔** | 用户手绘后首圈 12s;冷启动、预设与之后循环 6s | 笔尖沿路径移动,墨迹逐段落下。高性能档中新落下的一段线宽 2.7、不透明,在 0.5s 内收敛到线宽 2.0、90% 不透明;低性能档使用单段等宽 Path |
| **收笔** | 0.8s | 轨迹闭合瞬间,所有辅助圆和连杆在 0.3s 内淡到 4%;完整图形独自停留;右下角淡入一枚朱砂小方印 |
| **翻页** | 0.5s | 整幅(墨迹 + 印)淡出,辅助圆淡回起始态,下一轮开始 |

**四个设计意图**

1. **原稿幽灵常驻**。手绘笔迹不完全消失,以 12% 透明度留在底层。M = 256 时两者重合;拖到最左端时只剩基础椭圆轮廓,"逼近"变成肉眼可见的间隙。正方形预设用来展示低频轮廓与高频细节的关系,不再宣称经典吉布斯现象。
2. **湿墨头**。刚落下的笔画更粗更黑,随即收敛。这是纸本方案唯一的"运动感"来源,替代辉光拖尾。它属于高性能档视觉项,低档关闭后轨迹改为单次 stroke,不影响数学正确性。
3. **收笔落印**。这是全产品唯一一处非交互高光动效。它给循环一个呼吸点——没有它,画面是一直在动的白噪声;有了它,每一轮都有起承转合。朱砂印同时呼应「完成一幅作品」的文化语义。
4. **手绘揭晓慢放**。只有用户成功手绘后的第一轮用 12 秒;冷启动和点击预设直接用 6 秒,之后循环也用 6 秒。

拖动阶数时,核心教学交互优先于装饰时序:立即取消收笔、落印和翻页,进入稳定运笔态;松手后先走完当前一圈,再正常进入收笔和翻页,不补放被取消的落印。

**空闲轮播(P2,第一砍项)**:仅当前内容来自预设时,20 秒无操作后切换到下一个预设,0.5s 交叉淡入。保留 M,退出手动选频。用户手绘作品绝不被轮播覆盖。

## 五、原理呈现机制(本作品的教学核心)

### 5.1 要解决的问题

一堆圆转出一只猫,观众的反应是「哇好厉害」,不是「哦我懂了」。这两者差着一面旗的分数。要让人真的看懂,必须搭三座桥。

### 5.2 三座桥

| 要讲清楚的事 | 用户动作 | 屏幕反应 |
|---|---|---|
| **一个圆 = 求和式里的一项** | 点击频谱任一柱(P1,可独立回退) | 该项从求和式中展开;若它属于当前部分和,对应圆变朱砂并加粗;旁边显示真实半径、起始角和旋转方向 |
| **圆链 = 求和** | 拖动阶数滑块 | 求和范围 `|k|≤M` 实时变化;`±k` 从链尾成对加入,墨迹逐步贴近原稿幽灵 |
| **旋转 = 正弦波** | 默认即可观察;点击后可换项 | 常驻正弦条左侧显示放大的小圆,右侧显示它的两个完整投影周期;动点与主圆链共享 t |

**第三座桥最重要。** 大学生卡在傅里叶上,九成卡在「为什么复指数 e^(i2πkt) 和正弦扯得上关系」。「一个匀速转动的点,它的投影就是正弦波」——这句话配上那张图,是整个作品最有教学价值的六秒钟。

输入时翻转屏幕坐标的 y 轴,使正频率在画面中逆时针、负频率顺时针。单项文案直接写「每周顺时针转 3 圈」而不是只显示 `k=-3`;方向本身就是教学内容。

### 5.3 公式区设计

**位置**:内容层顶部,印在纸上,不放进浮层玻璃面板。公式是内容不是控件。

**默认态**

```
        f_M(t) = Σ cₖ · e^(i2πkt)
                  |k| ≤ M
```

M 的范围是 1…256;主标签写作「阶数 |k| ≤ 128」,不再使用「谐波 128 / 512」。默认自动模式中公式保持墨色;只有用户正在拖动滑块时,活着的 M 才使用朱砂。这样「朱砂 = 当前正在操作或手动选中的量」不破例。

**单项展开态**(点击频谱柱后)

主公式降到 40% 透明度并下压一条分隔线,其下展开:

```
        c₋₃ · e^(−i2π·3t)
   半径 24 · 起始角 0.8π · 每周顺时针转 3 圈
```

**这些数值必须来自用户自己画的那张图**,不能是写死的示例。这是本作品与一段教学视频的根本区别——公式里的数字是你亲手画出来的。

若手动选择的项当前不属于 `S_M`,单项公式与正弦条仍正常展示,圆链不高亮,并在公式下方显示:

> 阶数不够,这一项还没加进来

**返回**:再次点击同一柱、点击画布空白、切换预设、空闲轮播或成功手绘时,收起单项展开并恢复自动模式。若已选项发生「上一帧参与 → 当前帧不参与」,也立即恢复自动;选中时本就未参与的项不受这条规则影响。

### 5.4 正弦条默认项

自动模式不染朱砂,主公式保持总和,圆链不高亮。默认项按以下确定:

1. 令 `K = min(M, 32)`。
2. 在当前参与集的非零频率中求 `a_max`。
3. 从 K 向 1 递减扫描频率对,找到首个 `max(|c₊k|, |c₋k|) ≥ 1e-3·a_max` 的 k。
4. 在该对内选择振幅较大的 `+k` 或 `-k`;相等时选 `+k`。若全部为零,回退到 k = 0。

复杂曲线的正负频率不保证成对或等幅。k = 0 时不播放伪造的正弦,显示静态点与「零频不旋转,表示中心偏移;当前已归零」。

正弦条把所选小圆与波形按同一倍数放大,标注真实半径及「波形已放大」。横轴恒为两个完整局部周期;频率大小由动点速度和「每周顺/逆时针转 k 圈」表达。动点使用真实 k 与主动画共享 t,选择频率不得暂停或重置主动画。

### 5.5 频谱与手动选频

- 频谱固定显示 `-32…+32` 共 65 根柱,位置按真实 k,高度在可见项内线性归一
- 启用带由 `|k|≤M` 决定,从中心向两侧连续展开;M > 32 时两端显示溢出标记及窗口外参与项数,M = 256 时为 447
- 视觉柱保持窄;整张图使用容器级点击/拖动,按坐标吸附最近 k
- VoiceOver 把整张频谱暴露为可调节控件,逐项朗读「频率 +12,振幅 24,已启用」
- 自动模式不使用朱砂;手动选择的柱变朱砂并增高 2pt
- 手动选择未参与项时进入「选中且未参与」状态:频谱柱和公式保留选中态,正弦条播放,圆链无高亮
- 不提供 `|k|>32` 的手动入口,避免不可见高频在 6 秒周期、60fps 下产生时间混叠

## 六、布局:分层,不分区

### 6.1 层模型

```
系统层    状态栏、Home Indicator(不占用)
控件层    浮层玻璃面板(频谱 + 滑块)、预设按钮排
内容层    纸页——铺满全屏,延伸到控件层背后
          公式、辅助圆、原稿幽灵、墨迹轨迹、正弦条都在这一层
```

早期方案写的「画布占上方 65%,控制区占下方 35%」是**分区思维,已废弃**。纸页铺满整屏,控件浮在上面。收益是实打实的:圆链能用满整块屏。

### 6.2 浮层面板

全应用**只有一个**浮层面板,内含频谱条形图 + 阶数滑块。二者合并是因为它们本来就是同一件事——滑块控制的 `|k|≤M` 正是频谱里从中心向两侧启用的频率带。

- 规格:圆角 18,`Color.white.opacity(0.78)` + `.ultraThinMaterial`,1px `ink.opacity(0.12)` 描边,零阴影
- 遵守「不玻璃叠玻璃」「不给玻璃垫不透明底」
- 必须响应 `accessibilityReduceTransparency`:开启时降级为纯白不透明背景

预设按钮排在面板下方,不叠加在面板上。

### 6.3 空间适应

禁止任何基于设备型号的判断。用 `GeometryReader` 读容器尺寸:

- 宽度 < 500pt(iPhone 竖屏):单列,公式在上,其下常驻约 64pt 的紧凑正弦条;画布居中、面板浮于下方
- 宽度 ≥ 500pt(iPad / 横屏):画布居左占主体,公式与正弦条移至右侧栏常驻,面板贴右下

横竖屏切换保持上下文:当前 M、选中项、播放进度全部保留。iPad/常规宽度是展示基准,iPhone 必须完整可用;Mac Playgrounds 窗口需要从最窄到最宽连续缩放验证,中间尺寸不得截断、重叠或破坏公式换行。

## 七、组件清单与状态

| 组件 | 状态 |
|---|---|
| `PaperCanvas` | 默认播放 / 绘制中(旧作品 15%) / 手动单项高亮 / 选中未参与(无圆高亮) |
| `FormulaHeader` | 默认完整求和 / 拖动中(M 为朱砂) / 单项展开 / 单项未参与 |
| `SineStrip` | 自动 / 手动选中 / 选中未参与 / k=0 静态注脚 |
| `SpectrumBar`(单根) | 启用 / 未启用 / 手动选中 / 选中且未参与 |
| `OrderSlider` | 默认 / 拖动中 |
| `PresetButton` | 默认 / 选中 / 按下 |

**关于「状态六件套」的例外说明**

设计准则要求每个组件设计默认 / 加载 / 空 / 错误 / 成功 / 部分六种状态。本应用**不存在加载、错误、离线、部分状态**,因为:全部计算在本地完成且耗时 < 100ms;无网络请求;无失败路径;启动即有预设内容,不存在空状态。

为凑满六件套而设计用不上的界面,违反「每个元素必须配得上它占的位置」。此项例外记录在案。

唯一需要处理的边界:**采样点少于 10 个时视为误触**,不做任何提示;旧作品从 15% 淡回原状并恢复播放。只有有效新笔迹才替换旧作品。

## 八、文案

全部使用句式大小写,不用全大写标签。

| 位置 | 文案 |
|---|---|
| 初次启动提示 | 用手指画一个封闭图形试试 |
| 正弦条说明 | 一个匀速转动的点,投影就是一条正弦波 |
| 阶数滑块标签 | 阶数 \|k\| ≤ 128 |
| 辅助参与项数 / VoiceOver | 共 257 项参与 |
| 负频率方向 | 每周顺时针转 3 圈 |
| 零频注脚 | 零频不旋转,表示中心偏移;当前已归零 |
| 未参与选中项 | 阶数不够,这一项还没加进来 |
| 正方形提示(M ≤ 32,每次进入最多一次) | 低阶只画得出圆滑的东西,直角是高频堆出来的 |

初次启动提示在用户第一次成功绘制后**永久消失**。

正方形提示每次进入该预设最多显示一次;若进入时 M 已经 ≤ 32,立即淡入,无需等待跨越阈值。切换到其他预设或成功手绘视为离开,再次进入后可重新显示一次。

## 九、无障碍

- [ ] 正文与轨迹对比度 ≥ 4.5:1(见 §3.1 核算表)
- [ ] 不用颜色作为唯一信息载体:选中的频谱柱**同时**变朱砂色并增高 2pt;选中的圆**同时**变色并加粗
- [ ] 支持 Dynamic Type;公式区文字随之缩放,超宽时允许换行
- [ ] `accessibilityReduceMotion`:五阶段循环降级为静态完成态
- [ ] `accessibilityReduceTransparency`:浮层面板降级为不透明白底
- [ ] 所有控件有可访问性标签;预设按钮标注图形名称而非「按钮」
- [ ] 一般控件点击热区 ≥ 44×44;65 根窄频谱柱不各自伪造重叠按钮,而由整张图统一点击/拖动并吸附最近 k
- [ ] 频谱在 VoiceOver 下作为可调节控件,支持逐频率切换并朗读 k、振幅和参与状态

## 十、工期影响与降级顺序

原理呈现部分(§5)是本轮新增,预估增量约 2 小时,落在 PRD 排期的 H6–H8 区间。

时间不足时按此顺序砍:

1. 砍**空闲轮播**(§4),它是 P2 第一砍项
2. 若频谱命中测试阻塞交付,回退**手动选频**,但保留 65 柱频谱和自动正弦条
3. 不启动方波吉布斯加餐;它只有在全部硬验收、连续缩放测试和打包演练通过,且冻结前仍有至少 1 小时时才允许开始
4. **绝不砍**:标准频率截断滑块、公式实时 M、频谱可视化和自动正弦条。这四项共同构成最低教学闭环

主链路(手绘 → 分解 → 重建)在 PRD 的 H5 已经完成,以上全部是加分项,不存在交不出东西的风险。

## 十一、范围冻结

当前无待确认设计事项。不得恢复暗色青光方向、按振幅取前 M 项、正方形吉布斯误述或默认隐藏正弦条。任何新增功能必须重新经过优先级评审。
