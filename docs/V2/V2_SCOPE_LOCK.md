## 二、绝对不许碰

### 2.1 工程与依赖

- `Package.swift` —— 一个字符都不能动
- 不新增 SPM 依赖，不 import SwiftUI / Foundation / CoreGraphics 之外的任何框架
- 不用 UIKit、Metal、`.metal` 文件、Accelerate
- 不建第二个 target、不用 asset catalog、不读 Bundle 资源、不改 Info.plist
- 目标 iOS 17。**不许使用 `.glassEffect()`、`GlassEffectContainer` 或任何 iOS 26 起才有的 API**
- 不引入任何持久化

### 2.2 `Math/` 目录：整个只读

`Complex.swift`、`Resample.swift`、`DFT.swift`、`TrailCache.swift` —— **全部只读，一行都不改。**

> rev.1 曾允许给 `TrailCache` 新增一个 `maxDeviation` 方法。**该授权已撤销**：M4 改用尾部能量后不再需要它（见 §四）。

以下五条事实已通过闸门验证，任何"顺手优化"都会导致全盘返工：

1. `N = 512`，频率映射 `freq = (k < N/2) ? k : k - N`，故 `freq ∈ [−256, 255]`
2. 参与项数从实际频率集合计数，不能用 `2M+1`。**M = 256 时是 512，不是 513**
3. M = 1 时参与项是 3 个（−1、0、+1），轨迹是椭圆不是圆
4. 正负频率位置对称但振幅通常不成对
5. 输入端翻转 y 轴；正频率画面上逆时针，负频率顺时针

### 2.3 三条核心规则

- 纳入规则是**按频率截断** \(|k| \le M\)
- 圆链按频率排序 `0, +1, −1, +2, −2, …`
- 滑块映射 \(M = \mathrm{round}(1 + 255p^2)\)，范围 1…256

**不许为了让滑块和频谱 k 轴对齐而改映射公式。** 刻度不对齐是已知且接受的取舍。

### 2.4 已定型的产品决策

- 频谱窗口固定 `k ∈ [−32, +32]`，65 根
- 正弦条常驻，不许改回"点击才出现"
- 窄屏（< 500pt）与常规宽度（500–900pt）两个既有布局分支**代码路径一行都不许动**，只允许新增 ≥ 900pt 的第三个分支
- 不加欢迎页、教程页、开始按钮、登录页
- 预设坐标硬编码为 Swift 数组常量

### 2.5 朱砂色

朱砂只用于三种情形，全部属于"标记状态"：

1. 当前正被用户操作或选中的量（含 M2 差量窗口内新纳入的项）
2. 收笔完成印
3. 正弦条上与小圆同步的相位点

M2 的差量高亮 **900ms 后必须完全褪回石墨灰**。
公式释义第四行的 M **不上朱砂**——整条界面里只有主公式那个 M 是红的。

## 三、差量高亮的触发条件（rev.2 收紧）

**差量窗口只由 ⊕ 单步触发。**

⊕ 通过 `HarmonicSlider` 的 `onIncrease(oldM, newM)` 显式传给 `ContentView`；回调的默认空实现必须是显式初始化方法参数，使 Prompt 23 单文件修改后仍可编译。不得在 `onChange(of: m)` 里推测事件来源。

- ⊖ 不触发（新增集合为空，无内容可展示）
- 连续拖动滑块不触发（一次可能跨多阶，读数模板不成立）
- 空闲轮播、切换预设、手绘完成均不触发

这样 `deltaAddedFreqs` 恒为两项 `{+M₁, −M₁}`，唯一例外是 `M₁ = 256` 时只有一项 `−256`。读数模板因此是安全的。

这条限制同时也是教学上的正解：**「一阶一阶看」本来就是步进按钮的语义。**

## 四、平均偏离的定义（rev.2 更正）

rev.1 定义为最大逐点误差 \(\max_t |S_M(t) - S_{256}(t)|\) 并要求它随 M 单调下降。**这在数学上不成立**，在本工程自己的测试形状上 M = 17、20、28、30 处即出现回升，验收条件永远无法稳定通过。

改用**尾部能量 RMS**。由 Parseval：

\[
\left\| S_M - S_{256} \right\|_{L^2} = \sqrt{\sum_{|k| > M} \left| c_k \right|^2}
\]

每增加一阶就从尾部减去一个非负项，因此**全域严格非增**，M ∈ [1, 256] 已全量验证零反例。

实现时在 M 或系数变化时直接遍历 512 个 `Epicycle` 求尾部能量。不建后缀表，不为这点开销增加缓存状态，**不碰 `TrailCache`**。

状态存数学单位，只在 ≥ 900pt 新布局使用现有共享纯函数 `paperScale(for:in:)` 转成 pt。不要复制缩放公式。

界面文案：主标签「墨迹与原稿的平均偏离」，提示行「阶数每加一阶，这个数不会变大」。某阶系数可能为零，一位小数也可能让相邻两阶显示相同，因此不得写成「一定变小」。
**不要再叫「最远差」**——那是另一个量，且它不单调。
