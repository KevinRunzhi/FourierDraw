## V2 增量约束（2026-09-02 起生效 · rev.2）

V2 是纯增量。它只做六件事，其余一切保持原样：

```
L1  iPad 常规宽度布局（宽度 ≥ 900pt 的新分支）   ContentView
M1  公式释义 + 画布锚点 / 转向弧 + 合并无障碍描述   FormulaHeader / PaperCanvas / ContentView
M2  阶数差量高亮                                ContentView / PaperCanvas / FormulaHeader
M3  阶数步进按钮 ⊖ ⊕ + `onIncrease` 回调             HarmonicSlider
M4  平均偏离读数                                ContentView / FormulaHeader
M5  首轮引导字幕                                新建 FirstRunCaptions / ContentView
```

上表之外的文件改动一律视为越界，plan 阶段直接打回。

### 新增的五条硬约束

1. **布局断点只增不改。** 现有 < 500pt 与 ≥ 500pt 两个分支的代码路径一行都不许动，只允许新增 ≥ 900pt 的第三个分支。
2. **不许使用 iOS 26 起才有的 API。** 特别是 `.glassEffect()`、`GlassEffectContainer`。浮层面板继续用 `Color.white.opacity(0.78)` + `.ultraThinMaterial`。
3. **`Math/` 整个目录只读**，包括 `TrailCache.swift`。M4 直接遍历已有 512 个系数求尾部能量，不建后缀表。
4. **不许为让滑块和频谱刻度对齐而修改映射公式。** \(M = \mathrm{round}(1 + 255p^2)\) 与线性 k 轴刻度不对齐是已知且接受的取舍。
5. **平均偏离禁止进入 `Canvas` 绘制闭包。** 只在 M 变化时算一次并存进 `@State`。
6. **差量高亮只由 ⊕ 单步触发。** ⊕ 必须通过显式初始化参数 `onIncrease(oldM, newM)` 把事件传给 `ContentView`；不得在 `onChange(of: m)` 里推测。⊖、连续拖动、轮播、切预设、手绘完成一律不触发。
7. **差量的旧轨迹由 `ContentView` 在 M 改变前快照成 `previousTrail: [CGPoint]`**，画布只负责绘制，不做任何重算。

### 朱砂色补充第三种情形

朱砂现在允许出现在三处，全部属于"标记状态"：

1. 当前正被用户操作或选中的量（**含差量高亮中刚纳入的项**）
2. 收笔完成印
3. 正弦条上与小圆同步的相位点

差量高亮 **900ms 后必须完全褪回石墨灰**，残留即违规。
公式区释义第四行的 M **不上朱砂**——整条界面里只有主公式那个 M 是红的。

### 平均偏离的定义

用尾部能量 RMS，不是最大逐点误差：

\[
E(M) = \sqrt{\sum_{|k| > M} \left| c_k \right|^2}
\]

由 Parseval，它随 M 严格非增。最大逐点误差 \(\max_t |S_M - S_{256}|\) **不单调**，不许使用。
实现时直接遍历 512 个 `Epicycle`，状态存数学单位；只在 ≥ 900pt 新布局调用已有 `paperScale(for:in:)` 转成 pt，不复制缩放公式。界面文案用「平均偏离」与「不会变大」，不许叫「最远差」或写「一定变小」。

### 差量项数的算法

新纳入的频率必须从**实际频率集合取差集**，不许用 `2M+1` 推算：

```
added = { k : |k| ≤ M₁ } \ { k : |k| ≤ M₀ }
```

M = 255 → 256 时 `added` 只有一项 `−256`，因为集合里没有 `+256`。

### 步进的反函数

滑块绑定值是 \(p\)，步进必须走反函数：

\[
p' = \sqrt{\frac{M' - 1}{255}}
\]

写完必须对 M ∈ [1, 256] 全域验证 `round(1 + 255 · p'²) == M'`，并把 print 输出贴出来，不许口头声称通过。

### 画布标注的位置

三条锚点标注的位置从几何实时推导，**不许硬编码坐标**——图形是用户画的，每次都不一样。
做法：先算原稿幽灵路径的包围盒，再在画布边距中挑一个不与包围盒相交的位置放标签，并夹紧在画布可见范围内。
不许使用 ①②③ 编号标记。
