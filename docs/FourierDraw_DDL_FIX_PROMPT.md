# FourierDraw DDL 前收尾修复 Prompt

本轮只修复三个既有问题，不增加任何新功能。

## 工作方式

- 分两步，每步单独编译。第一步编译通过后再做第二步。
- 每步先读文件、给出计划，经批准后再写代码。
- 每次输出完整文件，不输出 diff。
- 不修改 `Package.swift`，产品名保持 FourierDraw。
- 不增加依赖，`Math/` 只读，不使用 iOS 26 API。
- 有关键歧义时先询问，不猜 API。

## 第一步：原稿虚线加深

定位用户手绘或预设原稿的幽灵路径，仅调整以下视觉参数：

```text
stroke-opacity  → 0.34
lineWidth       → 1.3
dash            → [5, 3.5]
```

当前源码的实际基线是常态透明度 `0.12`、线宽 `1.2`、虚线 `[4, 4]`。实施时将常态透明度改为 `0.34`，并把起稿阶段的淡出终点同步改为 `0.34`，即淡出系数 `0.88 → 0.66`；除此之外不改任何绘制或动画逻辑。

验收：将滑块拖到低阶（M ≤ 10），虚线原稿清晰可辨，能看出它与实线墨迹之间的缝隙。

## 第二步：`ContentView.swift` 修滑块并改文案

### 2.1 将底部控制面板锚定到安全区底部

- 通过根视图 `.safeAreaInset(edge: .bottom)` 或等价的 `.overlay(alignment: .bottom)` 锚定 `bottomPanel`。
- 内容行使用 `.frame(maxHeight: .infinity)` 消化剩余高度。
- 不通过增加高度或 padding 硬凑位置。
- 面板高度从 172 调整为 148。
- 面板内部视觉顺序恢复为：标签行 → 频谱 → k 轴刻度 → 滑块。
- 滑块位于最下面一行，必须可拖动。
- ⊖、⊕ 保留为禁用占位状态，本轮不实现按钮功能。

### 2.2 标题区文案

```text
大标题  圆迹                         20pt sans，ink
副名    OrbitInk                     13pt serif，ink 45%，紧跟大标题右侧
副标题  让傅里叶重新画出你的笔迹       12pt sans，ink 55%
```

删除「手绘任意封闭图形，用一串旋转的圆重新画出来」。不修改 `Package.swift` 或状态栏中的 FourierDraw 产品名。

### 2.3 画布下方两行提示

```text
用手指在这里画一个封闭图形                         15pt sans，ink 80%
虚线是你画的原稿，实线是圆链重新画出来的             11pt sans，ink 45%
```

两行均居中，第一行视觉上明显大于第二行。

## 整轮验收

1. iPad 横屏时底部面板完整可见，滑块位于最下面一行且可拖动，阶数和图形随拖动更新。
2. M ≤ 10 时，虚线原稿清晰可辨，能看出与实线的缝隙。
3. 左上角显示「圆迹 OrbitInk」及「让傅里叶重新画出你的笔迹」。
4. 画布下方显示两行提示，第一行明显大于第二行。
5. 窗口从 1400pt 缩到 800pt 再拉回时，面板始终贴底且不被裁切。

## 禁止方案

- 修改 `Package.swift` 或产品名。
- 用调整高度或增加 padding 的方式硬凑面板位置。
- 修改本 Prompt 未明确要求的内容。
